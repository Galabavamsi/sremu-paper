\section{Future Work}\label{sec:future}

Several extensions would widen the reach of \sremu{} without changing its time model.
\emph{Validation.} \claim{C-NEXT-VALIDATION}The next validation step is the open sub-6\,GHz
data set of Rossanese et al.~\cite{Rossanese2024OpenMeas}: beam scans of a surface with a
documented chamber geometry. Its comparison needs a new analysis plan, locked before the
emulator is run on the data: the measured columns sit on a floor that does not depend on the
configuration, the cells have seven phase states and an absorbing
state~\cite{Rossanese2022WiNTECH} rather than an ideal alphabet, and the descriptive structure
of the data has already been seen, so the comparison can be pre-specified but not blind. A
data set with a measured reconfiguration transient would also move parts of the model card
from consistency checks to validation. \emph{Unmodified radio software.} A virtual-USRP layer
of the kind ACHEM provides~\cite{Gurses2026ACHEM} would let unmodified UHD applications use
the emulator. srsRAN was not run in this version: its 4G stack would have to be built from
source for the test platform, its ZMQ radio driver~\cite{srsRANZMQ} ties its transmissions to
its receive calls, so that a lockstep peer would have to offset the two streams to avoid a
stall (from reading the driver, not tested), and an attach test needs two peers at LTE sample
rates, where lockstep exchange would run slower than the wall clock. \emph{Network control.}
An adapter for the E2 service model for RIS~\cite{ElGhalbzouri2025GoSimRIS,Kayraklik2026ORIX}
would connect O-RAN applications to the control plane, and authenticated sockets would allow
control across hosts. \emph{Physics.} Mutual coupling could enter through a mutual-impedance
model~\cite{Gradoni2021MutualCoupling} instead of tables; RIS--RIS paths would allow several
interacting surfaces; frequency-dependent reflection filters would accept signals wider than a
table's validity bandwidth; and polarization and non-reciprocal tables would cover more
hardware. \emph{Runtime.} Rate conversion between streams of different rates, a pipeline
resident on a graphics processing unit (GPU) for large arrays, a transport outside the
engine's interpreter for the served data plane, and vectorized learning environments with IQ
backends would extend the scale of experiments.
